# bilimini 桌面版

藏起来！哔哩哔哩 —— 一个可以摸鱼的 B 站桌面客户端。

小窗口、总在最前、一键隐藏，专为「只有一块屏幕又想在工作间隙刷 B 站」的场景设计。

> 本项目基于 [chitosai/bilimini](https://github.com/chitosai/bilimini) 二次开发，在此基础上做了功能补充与体验修复，详见 [与原项目的关系](#与原项目的关系)。


## 功能

**继承自原项目**

- 无边框小窗口，始终置顶
- 全局快捷键一键隐藏（默认 `Ctrl+E`，Mac 下 `Option+W`），隐藏时自动暂停播放
- 窗口透明度可调
- 分 P 选择、弹幕开关、动态页
- 支持 Windows / macOS

**本项目新增与改进**

- **首页推荐自动换新** —— 每次打开软件、每次从视频页返回首页，都会自动拉取一批新的推荐视频，不再反复看到同样的内容
- **顶栏刷新按钮** —— 在首页随时换一批推荐
- **收藏夹浏览** —— 个人空间内补上「收藏」入口，支持收藏夹列表 → 进入收藏夹查看视频的两级浏览，排版与主页保持一致
- **横竖版自适应窗口** —— 播放页自动进入网页全屏；横版视频用横向窗口、竖版视频用竖向窗口，避免大片黑边
- **窗口尺寸记忆** —— 主页与播放页分别记住各自的窗口尺寸，互不干扰
- **倍速播放** —— 顶栏倍速按钮（悬停展开菜单），支持 0.75x / 1x / 1.25x / 2x；换 P、切清晰度、自动跳下一集时自动保持所选倍速，与 B 站播放器自带倍速菜单双向同步
- **移除作者服务器依赖** —— 原版的检查更新逻辑会请求已失效的作者服务器，且返回内容非 JSON 时会抛异常，本项目已移除该逻辑，启动不再报错
- **规范化 `bilibili://` 协议处理** —— 拦截桌面端无法处理的 App 唤起协议，避免弹出「获取打开此链接的应用」系统对话框

## 安装

从 [Releases](../../releases) 下载最新的 `bilimini-Setup-x.x.x.exe`，双击安装即可。

安装包不包含任何账号信息，登录状态保存在本机（`%APPDATA%\bilimini`），首次启动登录你自己的 B 站账号即可。


## 开发

```bash
npm install
npm start
```

打包：

```bash
npm run win64   # Windows 64 位
npm run win32   # Windows 32 位
npm run mac     # macOS
```


## 与原项目的关系

本项目是一个**修改版（不是 Fork）**，源码以 [chitosai/bilimini](https://github.com/chitosai/bilimini) 为基础，作者为 [@千歳](https://github.com/chitosai)。

- 原项目地址：https://github.com/chitosai/bilimini
- 原项目介绍：小窗口、总在最前、支持全局快捷键隐藏的 B 站桌面客户端
- 本项目在其基础上修改了路由逻辑、播放器适配、收藏夹展示等模块，并移除了原作者的服务端依赖

原项目**未附带开源协议文件**。本项目仅作个人学习与自用交流，不对原项目的授权状态做任何主张。
如果你是原作者并希望调整本项目的使用方式，请通过 Issue 联系。


## 说明

- 界面与功能大多基于 B 站已有的网页实现，本项目不抓取、不存储任何用户数据。
- B 站的页面结构与接口会不定期调整，若某天部分功能失效，通常需要相应更新解析逻辑。
- 本项目仅供学习交流，请勿用于商业用途。
